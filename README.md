# Police Chase 3D — Remastered 1.0

A clean remastered runtime based on the uploaded V7 project, preserving its existing game UI/shop/garage data while adding a stable independent driving runtime.

Run START GAME.bat, then use http://localhost:3000.

Controls:
W/Up gas
S/Down reverse
A/D or arrows steer
E hold = Nitro/Boost
M = world map
Esc = menu

Menu:
Location: City / Mountain / Desert
Time: Morning / Day / Night
Weather: Clear / Rain / Snow

Online uses a built-in same-origin WebSocket server; no npm `ws` package is required.
